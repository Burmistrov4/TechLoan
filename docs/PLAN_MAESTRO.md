# PLAN MAESTRO — TECHLOAN

> **IMPORTANTE:** El profesor actualizó el requisito del proyecto. Este plan reemplaza el enfoque anterior centrado en Tkinter.
>
> Fuente académica vigente: `Proyecto Práctico  Sistema Web CRUD con Flask y SQLite3.pdf`.

## Objetivo final

Entregar una aplicación **web CRUD funcional** con:

- Flask/Python.
- SQLite3.
- Jinja2.
- HTML5.
- CSS3 responsive.
- JavaScript Vanilla.
- consultas SQL parametrizadas.
- código modular.
- README.
- schema.sql.
- al menos 3 registros de prueba.
- pruebas y flujo de exposición.

## Estado heredado

El backend de TechLoan ya cuenta con modelos, servicios, autenticación, roles, permisos, validaciones, reservas, préstamos, devoluciones, disponibilidad, historial y pruebas.

La interfaz Tkinter existe, pero ya no es la prioridad académica.
