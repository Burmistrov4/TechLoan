Cómo funciona

Operativo en tres pasos

Sin infraestructura que contratar ni configuraciones eternas.

Prepara la base de datos

Un solo comando reconstruye el esquema completo a partir de schema.sql, con tablas, relaciones, índices y datos de ejemplo.

Arranca y accede

El servidor local se levanta en segundos. Entras con tu usuario y el panel aparece con los indicadores del día ya calculados.

Gestiona y consulta

Reserva laboratorios, presta equipos, devuélvelos y revisa el historial. Todo queda registrado y disponible para exportar.

Seguridad

Diseñado para que nada se pierda por el camino

Un sistema de gestión vale lo que vale la confianza en sus datos. TechLoan aplica las mismas prácticas que se exigen en entornos profesionales.

  • {{ ic.icono('candado') }} Contraseñas como hash Nunca se guarda ni se muestra la contraseña; solo su huella cifrada.
  • {{ ic.icono('escudo-ok') }} Permisos por rol, revalidados El rol y el estado del usuario se comprueban contra la base de datos en cada acción.
  • {{ ic.icono('auditoria') }} Auditoría inmutable El registro sobrevive a la baja del usuario y conserva su nombre como evidencia.
  • {{ ic.icono('llave') }} Identidad tomada de la sesión Quién ejecuta una operación lo decide el servidor, nunca un campo del formulario.

Preguntas frecuentes

Lo que suelen preguntar

¿Necesito internet para usarlo?

No. TechLoan funciona por completo en local: el servidor, la base de datos y los estilos viven en tu equipo. Internet solo hace falta para instalar las dependencias la primera vez.

¿Qué pasa si dos personas reservan la misma hora?

La segunda reserva se rechaza. El sistema compara los intervalos reales (inicio existente < fin nuevo y fin existente > inicio nuevo) dentro de la misma operación, y además ofrece las franjas libres más cercanas. Las reservas que solo se tocan —una termina justo cuando empieza la otra— sí se permiten.

¿Dónde se guardan los datos?

En un único archivo SQLite dentro del propio proyecto. Eso hace que hacer copia de seguridad sea tan simple como copiar un archivo, y que puedas mover toda la instalación de un equipo a otro sin exportar nada.

¿Se pueden separar los permisos del personal?

Sí. El rol ADMINISTRADOR gestiona usuarios, elimina registros y consulta la auditoría. El rol OPERADOR trabaja las reservas y los préstamos del día a día, pero no ve el módulo de usuarios ni puede eliminar catálogo.

¿Es difícil de mantener?

Depende de dos paquetes: Flask y Werkzeug. La interfaz es HTML, CSS y JavaScript sin frameworks, así que cualquiera con conocimientos básicos de desarrollo web puede leerla y modificarla.
